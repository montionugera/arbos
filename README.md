# Arbos

Arbos is being rebuilt.

The design is in [docs/design/arbos-rebuild-ideation.md](docs/design/arbos-rebuild-ideation.md).
Current status is in [docs/STATUS.md](docs/STATUS.md).

This tree is the starting layout:

- `app/` is zeron, imported from [zeronsh/zeron](https://github.com/zeronsh/zeron).
- `fx/` is fx, imported from [vercel-labs/fx](https://github.com/vercel-labs/fx).
- `ios/` is empty until phase 6.

The product is not branded Arbos yet, and it is not installable yet.

The root license is MIT. `fx/` stays Apache-2.0. See `fx/LICENSE` and the `THIRD_PARTY_NOTICES.md` files in `app/` and `fx/`.
