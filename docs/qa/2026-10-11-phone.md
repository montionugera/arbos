# Phone, 2026-10-11

The phone lists projects, follows Main, and queues a prompt. It uses the same RPC as the desktop. This machine is Linux, so there is no iOS simulator and no phone screenshot. The proof is the Rust test below. This note has no tokens.

## What the phone does

`ios/` is a SwiftUI app. On screen it says `Arbos 0.2.111`. A person pastes an engine URL that starts with `ws://` or `wss://`, optional Cloudflare Access fields, and connects. The app lists projects, follows that project's Main chat, and sends a prompt.

The frames are `ArbosCall` with `op` `projects`, `WatchDocMessages`, and `QueueCommand`. They go to `GET /v1/rpc` on the home engine port. Localhost IPC still rejects an `Origin` header. The Rust client is `app/crates/phone` (`zeron-phone`). `app/crates/mobile` is the voice and orb core and is not linked. There is no voice and no call screen.

The clap command name is `Arbos`. The package and the on-disk binary stay `zeron`.
