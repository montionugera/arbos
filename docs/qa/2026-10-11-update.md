## Scratch install

The previous edge tarball, `arbos-0.2.111-linux-x86_64.tar.gz`, was installed with `HOME=/tmp/arbos-managed-home`. That home is not the real home directory. `install.sh` printed `Installed Zeron 0.2.111`.

`/tmp/arbos-managed-home/.zeron/app/current/zeron --version` printed `Arbos 0.2.111`.

`current` pointed at `/tmp/arbos-managed-home/.zeron/app/0.2.111`.

The 0.2.111 binary contains the button label `Restart to update` (`update-prompt-restart`). This machine has no user service bus, so a service restart cannot run here.
