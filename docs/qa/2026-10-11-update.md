## Why the strip stays hidden

The sidebar strip appears only when the feed version is newer than this binary. These two versions are the same, so the strip stays hidden.

The restart label is `Update ready — restart to apply`. That label is the ready state of a self-updating install. On Linux, a self-updating install is a managed copy under `~/.zeron/app`. This binary is a source build. A source build is unmanaged. If a newer version existed, the unmanaged strip would say `Update available — v<version> · download from GitHub`. It would not offer a restart.

There is no Mac app bundle here. The MacBook is offline. This tree does not publish a disk image.
